# Welcome

Welcome to the Investhub developer and product documentation.

## What is Investhub?

Investhub provides a legal and compliant solution for onboarding investors, from individuals to large groups. The platform supports tokenization of shares, bonds, and other financial instruments, with wallet-based investing and multiple payment options.

* [**API Reference**](overview/) — Backend APIs (Supabase Edge Functions), authentication, base URL, and the full OpenAPI spec for all endpoints.
* [**Investments guide**](guides/investments.md) — Creating an investment, payment methods, and the main API flow.
* [**Portfolio Dashboard guide**](guides/portfolio-dashboard.md) — Net worth overview, allocation chart, transaction history, CSV export, caching, and testing checklist.
