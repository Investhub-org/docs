# x402 (paid agent calls)

Some InvestHub calls are free. Some are not ready to run until the caller pays. HTTP **402 Payment Required** is how the server says that. [x402](https://www.x402.org/) is the protocol an agent uses to pay that call in USDC on Base, then retry the same request with proof of payment.

This page does not set prices for the MCP tools. Where a price is not already published, it is marked TODO. Do not invent one.

::: warning Not investment advice
Paying for an API call is not an investment, and it is not advice. Offerings are offered via a licensed partner (in review). InvestHub does not hold an ECSP licence. The interface fee goes to the Digihub.li Genossenschaft. Tokenized stocks (Coinbase B20 "c" tokens) are not for US persons.
:::

## How a paid call works

1. The agent calls the endpoint with no payment header.
2. The server answers **402** and lists what it will accept: scheme, network, amount, and the USDC asset.
3. The agent's wallet signs a payment authorization. On the white-label tenant API this is an ERC-3009 `transferWithAuthorization` on Base. The InvestHub server does not sign that authorization.
4. The agent retries the same call with the signed payload in the `X-PAYMENT` header.
5. The server verifies and settles the payment, then runs the call.

A 402 payment is separate from an investment, a vote, or a dividend claim. Those still come back as unsigned transactions. The person signs them in their wallet. See [Agents & MCP](/agents/mcp).

## Free tools

Reads, the catalog, and quotes are free:

- `about_investhub`
- `search_catalog`, `list_deals`, `get_deal`, `get_quote`
- `risk_profile_questionnaire`
- `list_meetings`, `get_meeting`, `gv_list_proposals`, `gv_get_proposal` (public metadata; a SIWE session does not by itself make the read a paid call)
- `get_claimable`
- `advisor_list_clients`, `advisor_client_view` (still refused without the client's consent)
- `propose_basket` (uses the catalog already loaded; it does not refresh prices)

`get_quote` can return unsigned swap transactions. The quote itself is free. Routes that charge an interface fee name that fee to the Digihub.li Genossenschaft. That fee is part of the swap, not an x402 charge for the MCP call.
